# Source Manifest

This bundle contains the available specifications, raw outputs, run metadata, and essay draft for the AI Werewolf project.

## Integrity rules

- Files under `v1/`, `v2/`, and `v3/` are source artifacts and must not be rewritten.
- Renaming and directory normalization have already been performed in this bundle.
- Documentation may summarize these files but must not silently correct them.
- Missing artifacts must be described as unavailable, not reconstructed.

## Contents

- `v1/specs/`: Final persona and Taste Test 001 specifications.
- `v1/output/`: Complete output for all three Version 1 games.
- `v2/specs/`: Version 2 personas, relationships, rules, and launcher.
- `v2/output/`: Complete available Version 2 output.
- `v3/specs/`: Version 3 personas, voice bible, relationships, rules, launcher, and instructions.
- `v3/output/`: Complete Version 3 public/private logs and edited cuts.
- `v3/metadata/`: Screenshots supporting Version 3 usage and runtime claims.
- `metadata/`: Structured run summary and notes supplied by the project owner.
- `evidence/`: Short, source-linked excerpts for the website essay.
- `docs/ESSAY_DRAFT.md`: Draft website essay with a repository URL placeholder.

## Known limitations

- Version 1's standalone launcher wrapper is not preserved as a separate raw file. The full operational prompt is embedded in `v1/specs/TASTE_TEST_001.md`.
- No machine-readable event log was produced for these runs.
- V1 player-call count was not recorded.
- V1 and V2 usage figures are approximate owner records; V3 includes screenshots.
